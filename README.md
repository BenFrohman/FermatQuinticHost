The real host is the Fermat quintic fourfold

```text
F5 = x0^5 + x1^5 + x2^5 + x3^5 + x4^5 + x5^5
V(F5) subset P^5
```

Certificate: [`Hodge/VF5.lean`](Hodge/VF5.lean) and [`CERTIFICATE.md`](CERTIFICATE.md).
`Hodge/NewHost.lean` is a placeholder filename, not the host name.

`hostLabel` is a string. `T_F` is not used. `Z` on the sextic is uncomputed.
Primitive `H^{3,1}` container dimension is 120, not 0.

Toolchain: Lean `v4.22.0`, Init only.
